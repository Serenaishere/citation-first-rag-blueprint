# Contributing

Contributions that improve clarity, reproducibility, security, or evaluation are welcome.

Before opening a pull request:

1. use synthetic or explicitly redistributable data only;
2. remove credentials, private URLs, personal information, and customer identifiers;
3. distinguish measured results from heuristics or starting values;
4. keep vendor-specific integrations optional;
5. run `npm test` in `examples/minimal-rrf`;
6. update the relevant security or evaluation notes when behavior changes.

Do not submit copied private prompts, production logs, scraped article bodies, proprietary documents, or API responses containing user data.
